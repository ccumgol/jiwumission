Hugo 테마 고르기 가이드

themes.gohugo.io에 등록된 275개 공식 테마를 용도별로 나누고, 각 테마가 어떤 사이트에 어울리는지·무엇을 조심해야 하는지 한국어로 정리했습니다. 아래에서 만들려는 사이트 종류를 먼저 고르세요.

기준일 2026년 7월 25일 · 출처 themes.gohugo.io (별점·업데이트일은 수집 시점 기준)

테마를 고르는 3단계
  1. 용도부터 — 블로그인지 문서 사이트인지 회사 소개인지. 용도가 다르면 아무리 예뻐도 고생합니다.
  2. 데모를 직접 열어보기 — 썸네일은 첫 화면일 뿐입니다. 글 목록·본문·모바일 화면까지 확인하세요.
  3. 관리 상태 확인 — 최근 1년 안에 업데이트됐고 사용자가 많은 테마가 훨씬 안전합니다. 이 페이지에서 초보 추천 표시를 참고하세요.

상황설명
Hugo "extended" 버전많은 테마가 일반 Hugo가 아닌 hugo extended를 요구합니다(SCSS를 쓰기 때문). 설치 시 extended 버전을 받으세요. 안 그러면 SCSS 관련 오류가 납니다.
Tailwind 기반 테마Tailwind 배지가 붙은 테마는 Node.js 설치와 npm install 과정이 추가로 필요합니다. 처음이라면 Tailwind가 없는 테마가 편합니다.
테마마다 설정이 다름같은 글이라도 테마를 바꾸면 화면이 깨질 수 있습니다. 테마의 exampleSite 폴더를 그대로 복사해서 시작하는 것이 가장 빠릅니다.
한글·다국어대부분 한글 본문은 문제없지만, 메뉴·날짜 표기 등 UI 번역은 다국어 배지가 붙은 테마가 훨씬 수월합니다.
댓글·검색·통계정적 사이트라 기본 기능이 없습니다. 댓글은 Giscus/Disqus, 검색은 테마 내장 기능이나 Pagefind 같은 외부 도구를 붙입니다. 테마 문서에서 지원 여부를 확인하세요.
라이선스MIT·Apache는 사실상 자유롭게 씁니다. GPL 계열은 수정본 공개 의무가 생길 수 있어 상업적 사용 전 확인이 필요합니다. 표기 없는 테마는 저장소에서 직접 확인하세요.
업데이트가 멈춘 테마Hugo는 업데이트가 잦아서 오래 방치된 테마는 최신 버전에서 빌드 오류가 납니다. 디자인이 마음에 들어도 2년 이상 멈춘 테마는 신중하게 고르세요.
이 문서는 themes.gohugo.io 공개 정보를 수집해 한국어로 재정리한 자료입니다. 별점·업데이트일·라이선스는 2026-07-25 수집 시점 기준이며 이후 달라질 수 있으니, 최종 결정 전 각 테마의 공식 페이지와 저장소를 확인하세요.
