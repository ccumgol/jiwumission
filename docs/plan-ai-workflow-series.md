# 시리즈 기획안 — "AI 오케스트라: 여러 AI를 조합한 실전 협업 워크플로우"

> 상태: **기획 확정 대기 / 집필 보류** (2026-07-31 저장)
> 우선순위 결정: FreeShow 시리즈는 캡처 화면이 많이 필요해 후순위로 미루고, 이 시리즈를 먼저 진행하기로 함.

---

## 1. 컨셉 한 줄

> "하나의 AI로 다 하려 하지 말고, **강점이 다른 AI들을 릴레이로 이어** 더 좋은 결과물을 만든다."

## 2. 타깃 & 차별점

- **타깃**: 개별 도구는 써봤지만(사이트의 Gemini·NotebookLM·프롬프트 강의 수강층) "어떻게 조합하느냐"가 막막한 중급 사용자, 그리고 소규모 교회·사역자.
- **차별점**: 도구 *소개*가 아니라 **실제 결과물(리포트·설교준비·뉴스레터·코드)을 만드는 파이프라인**.
  매회 ① 역할분담 플로우차트 ② 단계별로 넘겨줄 프롬프트 ③ 결과물 샘플 ④ 주의점(할루시네이션·보안·무료/유료 한계).

## 3. 핵심 골격 — 4단계 파이프라인

```
리서치(Perplexity·NotebookLM)
  → 구조화·집필(Claude·ChatGPT)
    → 산출물 형식화(Gemini·Notion AI)
      → 교차검증(Grok·Claude)
```

이 4단계를 먼저 개념으로 잡고, 뒤에서 실전 프로젝트에 반복 적용한다.

## 5. 매회 공통 템플릿

```
목표 → 준비물(사용 AI) → 파이프라인 플로우차트 → 단계별 프롬프트(복붙용)
     → 결과물 예시 → 흔한 실수·주의점 → 요약
```

- **폴더**: `content/class/ai-workflow/`

- **발행 주기**: 주 1회, '잎새' 소식지와 연동(7부는 잎새 자체를 소재로)

- 각 AI 서비스의 협업 워크플로우 (5개 프로젝트 실험 프레임 + 서비스별 하위 페이지)
- AI 서비스 비교 및 협업 활용 가이드 (강점 비교표 · 추천 조합 · 선택 기준 4문항)
