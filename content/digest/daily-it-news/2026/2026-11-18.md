## 1. 엔비디아 3분기 매출 1,158억 달러, 1년 새 103% 증가… 젠슨 황 "이사회가 원하면 복귀하겠다"

엔비디아가 젠슨 황 전 CEO가 물러난 뒤 처음으로 분기 실적을 발표했습니다. 10월 25일에 끝난 회계연도 2027년 3분기 매출은 1,158억 달러로 직전 분기보다 20%, 1년 전보다 103% 늘었습니다. 시장 예상(약 1,091억 달러)을 웃돈 수치입니다. 데이터센터 매출이 1,076억 달러(+110%)로 대부분을 차지했고, 순이익은 653억 달러였습니다. 4분기 매출은 1,300억 달러(±3%)로 내다봤는데, 중국 데이터센터용 칩 매출은 전망에 넣지 않았습니다. 차세대 AI 서버 '베라 루빈 NVL72'도 출하를 시작했으며 회사는 "역사상 가장 빠른 제품 확대"라고 밝혔습니다.

같은 날 젠슨 황은 사임 뒤 첫 입장문을 냈습니다. 세마포에 따르면 황은 "개인 생활에서 심각한 잘못"을 저질렀다고 인정하고 이사회의 독립 조사에 협조하고 있다고 밝혔습니다. 이어 직원·투자자·협력사·고객에게서 복귀 요청이 쏟아지고 있다며, 이사회가 "주주와 직원, 회사, 그리고 미국에 최선"이라고 판단한다면 CEO로 돌아가는 것을 "영광으로 여기겠다"고 했습니다. 엔가젯 등은 이사회 의장이 황의 복귀를 검토하지 않고 있다고 밝혔다고 전했습니다.

엔비디아 이사회는 '국가 안보·수출 통제 감독 위원회'를 상설 기구로 새로 만들었습니다. 회사의 국가 안보 팀과 무역 준수 팀이 이 위원회와 임시 CEO 콜레트 크레스에게 직접 보고하고, 외부 독립 전문가도 둡니다.

**왜 중요한가** — 경영권이 흔들리는 가운데서도 AI 칩 수요가 꺾이지 않았다는 점이 숫자로 확인됐습니다. 다만 누가 회사를 이끌지, 중국 수출 문제를 어떻게 정리할지는 아직 열려 있습니다.

## 2. 오픈AI, GPT-6.2 '아스트라'·'솔' 공개… "더 높은 성능을 3분의 1 비용으로"

오픈AI가 새 모델 GPT-6.2 아스트라(Astra)와 솔(Sol)을 내놨습니다. 아스트라는 가장 어려운 작업을 맡는 최상위 모델, 솔은 일상 업무용의 효율적인 모델입니다. 챗GPT 워크, 코덱스, API에서 쓸 수 있습니다. 오픈AI는 두 모델 모두 더 적은 출력 토큰으로 더 나은 결과를 낸다고 설명했습니다.

오픈AI 발표에 따르면 여러 단계의 전문 업무를 평가하는 'Agents' Last Exam'에서 GPT-6.2 아스트라는 이전 GPT-6 아스트라보다 5.2점 높은 점수를 3분의 1에 못 미치는 비용으로 냈습니다. 슬라이드·스프레드시트·문서가 "AI가 쓴 티가 덜 나고" 업계 양식을 더 잘 따른다는 점도 내세웠습니다. API 가격은 아스트라가 이전보다 20% 낮아졌고(100만 토큰당 입력 8달러, 출력 40달러), 솔은 GPT-6.1 솔 가격을 유지합니다.

다만 이 수치들은 오픈AI가 고른 평가 결과입니다. 디크립트는 가격에서는 경쟁사를 압박하지만 모든 벤치마크에서 앞선 것은 아니라고 짚었습니다.

**왜 중요한가** — AI 경쟁의 초점이 '누가 더 똑똑한가'에서 '같은 일을 얼마나 싸게 해내는가'로 옮겨 가고 있습니다. 쓰는 사람 입장에서는 같은 요금제로 더 많은 일을 맡길 수 있게 됩니다.

## 3. 마이크로소프트, 자체 AI 모델 6종 공개… "GPT-6.1 솔 성능의 98%를 40% 비용에"

마이크로소프트가 연례 행사 이그나이트에서 직접 개발한 AI 모델 여섯 가지를 공개했습니다. 악시오스에 따르면 코딩, 사이버 보안, 이미지, 음성 분야를 아우릅니다. 마이크로소프트 AI CEO 무스타파 술레이만은 범용 최상위(프런티어) 모델 개발도 상당히 진전되고 있다고 악시오스에 말했습니다.

대표 모델은 코딩용 'MAI Code 2'입니다. 마이크로소프트는 기업에서 흔한 코딩 작업을 재는 벤치마크 네 가지 평균에서 이 모델이 GPT-6.1 솔 성능의 98%를 40% 비용으로, 클로드 오퍼스 5.5 성능의 96%를 5% 비용으로 낸다고 밝혔습니다. 더 가벼운 'MAI Code 2 Flash'도 함께 나왔습니다. 다만 회사는 이 모델들이 기초 과학 연구나 아주 긴 에이전트 작업 같은 어려운 문제에는 아직 맞춰져 있지 않다고 스스로 밝혔습니다. 두 모델은 깃허브 코파일럿에서 쓸 수 있고, 같은 계열 모델이 엑셀·파워포인트·워드·팀즈에도 들어갑니다.

**왜 중요한가** — 오픈AI 모델의 최대 고객이던 마이크로소프트가 직접 만드는 경쟁자로 바뀌고 있습니다. 가격을 앞세운 '충분히 좋은' 모델이 늘수록 기업의 선택지는 넓어집니다.

## 4. 앤트로픽, 공모가를 희망 범위 상단 이상으로… 주문은 물량의 7배 가까이

블룸버그는 소식통을 인용해 앤트로픽이 IPO 공모가를 희망 범위(주당 70~78달러)의 상단이나 그 이상으로 정할 것이라고 투자자들에게 안내하고 있다고 보도했습니다. 팔려는 주식 수의 일곱 배 가까운 주문이 들어왔다고 합니다. 78달러로 정해지면 IPO로 904억 달러를 조달하고, 완전 희석 기준 기업 가치는 1조 4천억 달러가 됩니다.

월스트리트저널은 공모가가 80달러를 넘을 수 있고, 자문단이 기업 가치 1조 5천억~1조 6천억 달러 수준의 가격을 논의했다고 전했습니다. 공모가는 18일(수)에 확정되고 19일(목)에 거래가 시작될 예정입니다. 논의가 진행 중이어서 세부 내용은 바뀔 수 있습니다.

**왜 중요한가** — 이달 초 기술주 급락 때는 목표 가치를 채우기 어렵다는 관측이 나왔지만 분위기가 뒤집혔습니다. 역대 최대급 상장이 어떤 값에 성사되느냐가 AI 투자 열기를 가늠하는 온도계가 됩니다.

## 5. 캘리포니아, 웨이모 로보택시 고속도로 운행 금지… 웨이모는 미국 전역에서 고속도로 운행 중단

캘리포니아주 차량국(DMV)이 웨이모 로보택시의 고속도로 운행을 금지했습니다. 명령은 11월 11일에 내려졌고 17일에 공개됐습니다. 테크크런치에 따르면 DMV는 웨이모 차량 세 대가 벌링게임 근처 101번 고속도로의 공사 통제 구간에 들어간 일과, 샌프란시스코 280번 고속도로에서 고속도로 순찰대 차량과 얽힌 별도의 일을 이유로 들었습니다. DMV는 5월 18일의 비슷한 일로 제한과 시정 조치를 했는데도 공사 구간 진입이 되풀이됐다며 "공공 안전에 임박한 위험"이라고 판단했습니다. 제한은 웨이모가 효과적인 시정 조치를 입증할 때까지 유지됩니다.

웨이모는 캘리포니아 밖을 포함해 영업 중인 모든 지역에서 고속도로 운행을 스스로 멈췄습니다. 웨이모는 현재 미국 15개 도시에서 영업합니다. 회사는 이번 일로 다치거나 부딪힌 사고는 없었으며, 일반 도로에서는 매주 50만 건이 넘는 운행을 계속한다고 밝혔습니다.

**왜 중요한가** — 고속도로 주행은 로보택시가 공항과 먼 거리로 서비스를 넓히는 데 꼭 필요합니다. 공사 구간 같은 예외 상황 대응이 여전히 숙제라는 점이 드러났습니다.

## 추천 GitHub 리포

- **[PaperOrchestra](https://github.com/google-research/paper-orchestra)** (GitHub 트렌딩) — 구글 클라우드 AI 연구진이 공개한 도구로, 여러 AI 에이전트가 역할을 나눠 AI 연구 논문 초안을 씁니다. 아이디어와 실험 기록을 넣으면 개요 작성, 관련 연구 조사, 본문 작성, 다듬기, 그래프 그리기를 각 에이전트가 맡아 학회 양식에 맞춘 LaTeX 원고로 만들어 줍니다. Python, Apache-2.0, 별 2,939개(오늘 하루 +1,175). GitHub 트렌딩 일간 페이지를 내장 브라우저로 열어 확인했고, 별 수는 GitHub API 값과 일치했습니다. 일간 상위의 Univer와 AG-UI는 이미 소개한 리포라 건너뛰었습니다.

## 오늘의 일반·사역용 추천 리포 (비영리·선교 행정)

- **[LibreTranslate](https://github.com/LibreTranslate/LibreTranslate)** — 내 서버에 직접 설치해 쓰는 무료 오픈소스 기계 번역기입니다. 구글·마이크로소프트 같은 회사의 번역 서비스에 기대지 않고 공개 번역 엔진(Argos Translate)으로 내 컴퓨터 안에서 번역하므로, 인터넷이 없는 곳에서도 쓸 수 있고 번역하려는 글이 바깥으로 나가지 않습니다. 다른 프로그램이나 홈페이지에 번역 기능을 붙일 수 있는 API도 제공합니다. Python, AGPL-3.0, 별 17,782개, 11월 14일에도 업데이트됐습니다. 선교 현장 소식이나 후원자 편지처럼 바깥 서비스에 올리기 조심스러운 글을 번역하거나, 여러 언어를 쓰는 교회·단체 홈페이지에 번역 기능을 넣을 때 유용합니다. 다만 번역 품질은 유료 서비스보다 떨어질 수 있어 중요한 글은 사람이 한 번 더 살펴보는 것이 좋습니다.
