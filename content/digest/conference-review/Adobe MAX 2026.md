## 1. 총평

Adobe MAX 2026은 **단일 벤더 크리에이티브 컨퍼런스**지만, 올해의 핵심은 새 기능 숫자가 아니라 **Creative Cloud의 문을 외부 AI 에이전트에 연 것**입니다. Adobe는 MCP(Model Context Protocol) 기반의 **로컬 MCP 통합(프리뷰)** 을 공개해, ChatGPT·Claude 같은 외부 에이전트가 사용자 PC의 Photoshop·Illustrator·Premiere·After Effects **네이티브 프로젝트 파일을 레이어·시퀀스·컴포지션이 살아 있는 상태로** 편집할 수 있게 하겠다고 밝혔습니다. Creative Boom은 이를 "2012년 Creative Cloud 출범 이후 가장 큰 변화 중 하나"로 평가했습니다.

**관통 주제 3가지**

1. **에이전트 3중 전략** — ① 외부 챗봇 안의 Adobe(Adobe Connector, 2025년 12월~) ② Adobe 앱 안의 에이전트(Adobe Creative Agent 기반 AI Assistant) ③ 외부 에이전트가 Adobe 앱을 직접 조작(MCP, 이번 발표). 서울경제가 정리한 이 3갈래 구도가 올해 MAX를 가장 잘 요약합니다.
2. **Firefly = 'AI 크리에이티브 스튜디오'** — 모델 생성기에서 Design·Video·Image·Graph·Builder를 묶은 **올인원 작업 공간**으로 재정의. 사용 가능 모델 수는 서울경제 1일차 보도가 **36개**, 같은 매체의 2일차 임원 인터뷰가 **외부 모델 약 30개**로 엇갈립니다 ⚠️(공식 수치 없음).
3. **리더십 교체기의 MAX** — 아닐 차크라바르티(Anil Chakravarthy)가 12월 1일 CEO에 오르고 샨타누 나라옌(Shantanu Narayen)은 이사회 의장(executive chair)으로 이동합니다. 1일차 키노트는 나라옌이 열고 차크라바르티가 이어받는 **'바통 터치' 구성**이었습니다.

**행사 종료 후 평가**: 2일차는 신기능보다 영감 중심의 키노트와 Sneaks로 채워졌고, 3일차는 키노트 없이 세션·인증·네트워킹으로 마무리됐습니다. 추가 제품 발표는 없었으므로 **1일차 발표가 사실상 올해 MAX의 전부**입니다. Sneaks에서는 Project Rinse Repeat가 기립박수를 받았고, 서울경제는 Deep Brush·Hands On의 반응이 가장 컸다고 전했습니다.

**한국 관점 핵심**: 어도비코리아의 별도 한국어 보도자료나 한국어 지원·국내 출시 일정 발표는 확인되지 않았습니다. 대신 **Firefly 국내 요금(스탠더드 월 15,200원 / 프로 30,300원)** 과 프로 할인 프로모션이 보도됐고, 2026년 1월 시행된 **AI 기본법의 생성형 AI 표시 의무**와 Adobe의 콘텐츠 자격증명(Content Credentials) 노선이 맞물리는 지점이 국내 실무에 가장 직접적인 연결고리입니다.

### 3-1. Creative Cloud 로컬 MCP 통합 — 외부 에이전트에 '툴 개방'

| 항목 | 내용 |
| --- | --- |
| 릴리스 상태 | **프리뷰(시연)** · 2027년 초 일부 사용자 대상 **비공개 베타** 예정(서울경제·MakeUseOf·위키트리). 현재 일반 사용 불가 |
| 대상 앱 | 공식 보도자료: **Photoshop, Illustrator, Premiere, After Effects** 4종. MakeUseOf는 InDesign·Lightroom·Express·Firefly·[Frame.io](http://frame.io/)를 더한 9종으로 보도 ⚠️(공식과 불일치) |
| 핵심 | 외부 에이전트가 사용자 PC의 **네이티브 파일**을 직접 편집. 레이어·벡터·빈·시퀀스가 **편집 가능한 상태로 유지** |
| 시연 | 키노트에서 Claude가 Premiere로 팟캐스트 핵심 구간을 찾아 컷 편집(MakeUseOf, Creative Boom) · ChatGPT 에이전트로 포스터의 도시·날짜만 바꿔 다수 버전 생성(서울경제) |
| 기존 자산 | Adobe Connector(Claude·ChatGPT·Gemini에 Adobe 도구 탑재), 공식 표현 "Anthropic, OpenAI, Slack 등과 출시한 커넥터를 기반으로" |
| 챗봇 측 연동 | ChatGPT·Claude·Gemini·Copilot 쪽 통합도 2027년 초 비공개 베타(Australian Photography) ⚠️ |
| 경쟁 제품 | Figma(MCP 서버), Canva AI 2.0 커넥터, Anthropic Claude Design |
| 출처 | Adobe 뉴스룸, Creative Boom, 서울경제, MakeUseOf, Feisworld |

**분석적 시사점**

1. **AI 기본법(2026년 1월 22일 시행)과의 연결** — 생성형 AI 결과물 표시 의무가 생긴 국내 환경에서, 외부 에이전트가 PSD를 편집하는 MCP 워크플로는 "누가(사람/에이전트/어떤 모델) 무엇을 바꿨는가"의 기록 문제를 키웁니다. Adobe의 Content Credentials가 국내 광고·방송 제작사의 컴플라이언스 도구로 부상할 가능성이 큽니다.
2. **광고·에이전시 업계** — "포스터의 도시·날짜만 바꿔 수십 개 버전"(ChatGPT 시연)과 Intelligent Reflow, Firefly 3D Digital Twin은 국내 대형 광고대행사·커머스의 **상세페이지·배너 대량 변형** 업무와 정확히 맞물립니다. 재촬영 없는 제품 이미지 생성은 커머스 MD 비용 구조를 바꿀 수 있습니다.
3. **K-콘텐츠 IP의 맞춤 모델** — 디즈니×Firefly Foundry 사례는 웹툰·애니메이션·엔터테인먼트 IP를 가진 국내 기업에 '자사 IP 전용 모델'이라는 선택지를 구체적으로 보여줍니다. 저작권 안전성(상업적 안전 학습)이 국내 IP 홀더의 핵심 구매 기준입니다.
4. **크리에이터 시장** — Premiere 모바일 Quick Cuts·UMG/WMG 라이선스 음원은 국내 숏폼 크리에이터 시장에서 CapCut과의 정면 경쟁을 의미합니다. 다만 음원 라이선스의 국내 적용 여부는 미확인 ⚠️.
5. **중국계 모델 포함** — ByteDance Seedance·Kling이 Firefly 모델 선택지에 들어간 만큼, 국내 공공·금융·대기업은 **모델별 데이터 처리 경로와 상업적 이용 조건**을 Model Selector 단계에서 통제하는 사내 정책이 필요합니다.
6. **Arm Windows PC** — Snapdragon이 스폰서로 참여하고 Adobe 앱이 Arm Windows에 최적화되면서, 국내 PC 제조사의 Arm 노트북 크리에이터 마케팅 여지가 넓어졌습니다.

## 8. 청중별 시사점

### 경영진

- Adobe의 메시지는 "AI 도구 구매"가 아니라 **"에이전트 시대의 창작 운영체제"** 입니다. 2027년 상반기 MCP 비공개 베타·상시 에이전트 베타 일정에 맞춰 예산·조직을 준비할 시점입니다.
- Canva·Claude Design·Figma와의 **도구 이원화 비용**을 재점검하십시오. 시안은 범용 AI, 최종 편집은 Adobe라는 분업이 Adobe가 그리는 그림입니다.
- 리더십 교체 직후라 요금·번들 정책 변동 가능성이 있습니다.

### 아키텍트 / 크리에이티브 테크 리드

- MCP는 **로컬 실행**입니다. 에이전트가 어떤 파일에 접근하는지, 클라우드 LLM으로 무엇이 전송되는지 **권한·로깅 설계**가 필요합니다.
- Firefly Graph(워크플로)·Always-on Agents(상시 실행)·GenStudio Coworker(캠페인 조율)의 **책임 경계**를 미리 정의하십시오. 세 계층이 겹칩니다.
- Model Selector 도입 시 모델별 상업적 이용·IP 면책 조건을 정책화하십시오.

### 디자이너 · 영상 편집자 · 개발자

- 지금 바로 쓸 수 있는 것: **Photoshop Relight**, **Premiere 27.0 Color Mode**, **Firefly Quick Actions**.
- 베타로 테스트할 것: Premiere AI Assistant(멀티캠 싱크·스트링아웃), Convert to Text Layers, InDesign Co-editing, Firefly Design.
- 개발자는 Firefly Builder 대기자 등록과 함께, MCP 공개 전까지 기존 Adobe Connector·UXP 스크립트로 자동화 파이프라인을 준비해 두면 전환 비용이 줄어듭니다.

## 10. 종합 평가

**강점**

- MCP 개방은 '편집 가능한 원본 파일'이라는 Adobe의 가장 강한 해자를 에이전트 시대로 옮기는 영리한 수입니다.
- 모델 중립 + Google·Microsoft·Disney 3대 파트너십으로 유통·모델·IP 축을 동시에 보강했습니다.
- Relight·Color Mode 등 **당장 쓰는 GA 기능**도 적지 않습니다.

**한계**

- 헤드라인(MCP·상시 에이전트·Builder)이 모두 **프리뷰~비공개 베타**이고 정식 출시 일정·가격이 없습니다.
- MCP 대상 앱 범위가 매체마다 4종/9종으로 엇갈리는 등 **커뮤니케이션 정합성**이 떨어집니다.
- 참가자 수·한국어 지원 등 기본 정보가 공개되지 않았습니다.

**다음 회차 관전 포인트**

1. MCP 비공개 베타의 실제 공개 범위와 **유료/무료 정책**
2. 차크라바르티 CEO 체제의 첫 요금제 개편 여부
3. Google DeepMind 맞춤 이미지 모델의 Photoshop 탑재 여부
4. Firefly 모델 라인업(36개/약 30개) 중 국내 상업 이용 가능 범위, 한국어 프롬프트 품질
5. 2027년 키워드로 언급된 **온디바이스 AI**의 구체화 — Arm Windows·RTX Spark 노트북에서 로컬 모델 실행 여부
