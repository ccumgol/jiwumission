# 계시록 17–18장의 구약 재직조(re-weaving)

## 0. 방법론적 전제 — 세 애가의 합성

계시록의 바벨론은 **하나의 본문을 인용한 것이 아니라 세 개의 심판 신탁을 융합**한 것입니다.

| 구약 원천 | 대상 | 죄의 성격 | 계시록에 기여한 요소 |
| --- | --- | --- | --- |
| 사 13–14, 21, 47 / 렘 50–51 | **바벨론** | 정치·종교적 자기신화 | "무너졌다", 금잔, 나오라, 여왕의 자칭 |
| 겔 26–28 | **두로** | 경제·해상 무역의 교만 | 상품 목록, 왕/상인/뱃사람의 3중 애가, 바다에 던짐 |
| 나 3:1–4 | **니느웨** | 음행·마술로 민족을 유혹 | 음녀(πόρνη) 이미지, 유혹의 언어 |

중요한 특징: **요한은 단 한 번도 인용 형식구(γέγραπται, "기록되었으되")를 쓰지 않습니다.** 계시록 전체에 명시적 인용 표지가 없습니다. 대신 구약 어휘를 자기 문장의 살로 삼습니다. Beale의 표현으로는 "구약이 계시록의 문법이 되었다"는 것입니다.

## 1. 계시록 17장 — 음녀의 정체

| 계시록 | 구약 원천 | 재직조 방식 |
| --- | --- | --- |
| 17:1 많은 물 위에 앉은 음녀 | **렘 51:13** "많은 물가에 살면서 재물이 많은 자여" | 유브라데 운하망이라는 지리적 사실 → 17:15에서 "백성과 무리와 열국"으로 **재해석** |
| 17:1–2 음녀, 땅의 임금들과 음행 | **나 3:4** (니느웨), **사 23:15–17** (두로) | 두 도시의 이미지를 바벨론에 이전 |
| 17:2 포도주에 취함 | **렘 51:7** "그의 포도주로 인해 열방이 취하였도다" | 거의 직역 수준 |
| 17:4 금·보석·진주로 꾸미고 **금 잔** | **렘 51:7** "바벨론은 여호와의 손에 든 금 잔" | 원문은 **하나님의 심판의 잔**, 계시록은 **음녀 자신의 가증한 잔** — 도구가 주체로 전도(轉倒) |
| 17:6 성도의 피에 취함 | **렘 51:49** | 이스라엘의 피 → 순교자의 피로 확장 |
| 17:16 벌거벗기고 살을 먹고 불로 사름 | **겔 16:37–41; 23:25–29** | 원래 **음녀 예루살렘**에 대한 심판 → 바벨론에 적용. 언약 백성 심판의 언어가 세상 체제로 향합니다 |

**17:4의 전도(轉倒)가 핵심입니다.** 예레미야에서 금 잔은 하나님이 쥐신 심판의 잔이고 바벨론은 그 잔에 불과했습니다. 계시록에서 그 잔은 음녀의 **손**에 있습니다. 도구였던 자가 스스로 주체가 되려 한 것 — 이것이 사 10:15("도끼가 도끼질하는 자에게 스스로 자랑하겠느냐")의 죄이며, 바벨론 심판의 근거입니다.

## 2. 계시록 18:1–8 — 선포와 부르심

| 계시록 | 구약 원천 | 비고 |
| --- | --- | --- |
| 18:2 **"무너졌도다 무너졌도다 큰 성 바벨론이여"** | **사 21:9** ἔπεσεν Βαβυλών (LXX) | 이중 동사까지 일치. 계시록의 가장 명백한 어구 차용 |
| 18:2 귀신의 처소, 더러운 새와 짐승 | **사 13:21–22; 34:11–14**, **렘 50:39; 51:37** | 폐허의 동물 목록(광야 짐승, 부엉이, 들양) → **귀신론적**으로 재해석 |
| 18:3 상인들이 사치로 치부함 | **사 47:15**, **겔 27:12 이하** | 두로의 경제적 죄가 이식됨 |
| 18:4 **"내 백성아 거기서 나오라"** | **렘 51:6, 45**; **사 48:20; 52:11** | 지리적 탈출 → **영적·윤리적 분리**(고후 6:17과 동일 계열) |
| 18:5 죄가 하늘에 사무쳤다 | **렘 51:9** "그 화가 하늘에 미쳤고 궁창에 달하였도다" | 창 11:4 "탑을 하늘에 닿게 하고"의 **역설적 성취** — 인간이 쌓아 올린 것 중 하늘에 닿은 것은 죄뿐 |
| 18:6 그가 준 대로, **갑절로** 갚으라 | **렘 50:15, 29**, **시 137:8** | *lex talionis*의 종말론적 적용 |
| 18:7 **"나는 여왕으로 앉은 자요 과부가 아니라"** | **사 47:7–8** "나는 영영히 여주인이 되리라… 나는 과부로 지내지도 아니하며" | **거의 인용**. 계시록에서 바벨론이 스스로 말하는 유일한 대사 |
| 18:8 **하루 동안에** 사망과 애통과 흉년 | **사 47:9** "일순간에 하루 동안에 자녀 잃음과 과부됨" | 사 47:8의 자랑과 47:9의 심판이 계 18:7–8에 그대로 이어 붙음 |
| 18:8 불에 살라지리라 | **렘 51:58** |  |

**사 47장이 계 18:7–8의 골격입니다.** 자랑의 문장과 심판의 문장이 순서까지 보존되어 있습니다. 사 47:8–9 → 계 18:7–8. 요한은 이사야의 논리 구조를 통째로 옮겼습니다.

한 가지 신학적 관찰: "나는 과부가 아니라"는 자칭은 **신부(νύμφη) 이미지의 참칭**입니다. 교회는 어린양의 신부이고(계 19:7; 21:2), 바벨론은 남편 없이도 여왕이라 주장합니다. 언약적 관계 없이 언약적 지위를 자칭하는 것 — 이것이 창 11:4 "우리 이름을 내고"의 종말론적 형태입니다.

## 3. 계시록 18:9–19 — 삼중 애가와 상품 목록

여기서 **원천이 이사야·예레미야에서 에스겔로 완전히 전환**됩니다. 겔 26–28장의 두로 애가가 구조 자체를 제공합니다.

### 3.1 구조의 차용

| 애가의 주체 | 계시록 | 에스겔 |
| --- | --- | --- |
| ① 땅의 왕들 | 18:9–10 | 겔 26:16–18 (해변의 왕들이 보좌에서 내려와 떨며) |
| ② 상인들 | 18:11–17a | 겔 27:12–25, 36 |
| ③ 선장·선원·뱃사람 | 18:17b–19 | 겔 27:26–32 |

세 계층의 순서와 반응 양식이 동일합니다. 각각 **"멀리 서서"** 보며(계 18:10, 15, 17) **"화로다 화로다 큰 성이여"**를 반복합니다. 이는 히브리 애가(קִינָה, *qinah*) 장르의 형식입니다.

### 3.2 상품 목록의 대조

| 계 18:12–13 (28개 품목) | 겔 27:12–24 대응 |
| --- | --- |
| 금, 은, 보석, 진주 | 겔 27:22 (스바·라마의 보석과 금) |
| 세마포, 자색, 비단, 붉은 옷감 | 겔 27:7, 16, 24 |
| 향목, 상아 그릇, 값진 나무 | 겔 27:6, 15 |
| 놋, 철, 대리석 | 겔 27:12, 19 |
| 계피, 향료, 향, 향유, 유향 | 겔 27:19, 22 |
| 포도주, 기름, 고운 밀가루, 밀 | 겔 27:17 |
| 소, 양, 말, 수레 | 겔 27:14, 21 |
| **종들과 사람의 영혼들** (σώματα καὶ ψυχὰς ἀνθρώπων) | **겔 27:13** נֶפֶשׁ אָדָם / LXX ἐν ψυχαῖς ἀνθρώπων (야완·두발·메섹이 사람을 매매함) |

**목록의 마지막 항목이 결정적입니다.** 계 18:13은 상품 열거를 "사람의 영혼들"로 끝맺습니다. 이는 겔 27:13의 히브리어 *네페쉬 아담*을 LXX 표현 그대로 가져온 것입니다. 요한은 두로의 노예 무역 항목을 목록의 **맨 끝, 강조 위치**로 옮겼습니다.

수사적 효과: 금에서 시작해 인간으로 끝나는 하강. 바벨론 경제의 논리적 종점이 인격의 상품화라는 진단입니다. 겔 27장에서는 40여 품목 중간에 묻혀 있던 것이, 계시록에서는 **고발의 절정**이 됩니다.

## 4. 계시록 18:20–24 — 종결

| 계시록 | 구약 원천 | 재직조 |
| --- | --- | --- |
| 18:20 하늘과 성도·사도·선지자들아 즐거워하라 | **렘 51:48** "하늘과 땅과 그 중의 모든 것이 바벨론으로 말미암아 기뻐 노래하리니" | 우주적 주체 → **교회 공동체**로 특정화 |
| 18:21 큰 맷돌 같은 돌을 **바다에** 던짐 | **렘 51:63–64** (책에 돌을 매어 **유브라데**에 던지라), **겔 26:12, 21** | 강 → 바다. 두로의 해양 이미지와 합성 |
| 18:22 거문고·퉁소·나팔 소리 없어짐 | **겔 26:13** "네 노래 소리를 그치게 하고 네 수금 소리를 다시 들리지 않게 하리라" |  |
| 18:22–23 맷돌 소리, 등불 빛, 신랑 신부의 음성 | **렘 25:10**; 7:34; 16:9 | 예레미야가 **예루살렘**에 선포한 저주가 바벨론에 반사됨 |
| 18:23 **복술(φαρμακεία)로 만국을 미혹함** | **사 47:9, 12** (바벨론의 사술과 진언), **나 3:4** (니느웨의 마술) | 정치권력을 종교적 미혹으로 규정 |
| 18:24 선지자와 성도들의 피 | **렘 51:49** |  |

**18:22–23의 렘 25:10 사용이 특히 예리합니다.** 예레미야는 그 저주를 **유다**에게 선포했고, 그것을 집행한 도구가 바벨론이었습니다. 계시록은 동일한 저주를 집행자에게 되돌립니다. 렘 50:15, 계 18:6의 "그가 준 대로 갚으라"가 문학적 층위에서 실현되는 셈입니다.

## 5. 종합 — 재직조의 다섯 원리

**① 지리의 상징화**
"많은 물"(렘 51:13, 유브라데 운하) → "백성과 무리와 열국과 방언들"(계 17:15). 요한은 자기 해석을 본문 안에 명시합니다.

**② 대상의 교체 (reversal)**

- 겔 16, 23: 음녀 = **예루살렘** → 계 17: 음녀 = 바벨론
- 렘 25:10: 저주 대상 = **유다** → 계 18:22: 바벨론
언약 백성 심판의 언어가 세상 체제로 향합니다. 벧전 4:17("하나님의 집에서 심판을 시작할 때가 되었나니")의 순서가 완결된 형태입니다.

**③ 도시의 합성**
바벨론(교만) + 두로(경제) + 니느웨(유혹) = 종말론적 바벨론. **어느 한 도시로 환원되지 않는 유형(type)의 창출**입니다. 그래서 1세기 로마를 지시하면서도 로마에 갇히지 않습니다.

**④ 세부의 승격**
겔 27:13의 노예 항목이 계 18:13의 클라이맥스로. 부차적 세부가 신학적 핵심으로 재배치됩니다.

**⑤ 시제의 전환**
사 21:9의 예언적 완료형 ἔπεσεν이 계 18:2에 그대로 보존됩니다. 아직 무너지지 않은 것을 이미 무너진 것으로 선포하는 것 — 이것이 순례하는 교회의 위로입니다. 이사야가 6세기의 유다에게 준 위로를 요한은 소아시아 일곱 교회에 그대로 전달합니다.

## 6. 대조 요약

| 항목 | 사 47 (바벨론) | 겔 26–28 (두로) | 계 17–18 |
| --- | --- | --- | --- |
| 핵심 죄 | 자기신화·사술 | 무역의 교만 | 둘의 합성 + 순교자의 피 |
| 여성 은유 | 처녀 딸 / 여주인 | (왕·성으로) | 음녀 |
| 심판 속도 | 일순간에, 하루 동안에 | 하루아침에 | 한 시간 안에 (18:10, 17, 19) |
| 애도자 | 없음 | 왕·상인·뱃사람 | 왕·상인·뱃사람 |
| 종결 행위 | 불 | 바다 속으로 | 맷돌을 바다에 |
| 교회의 위치 | "나오라"(사 48:20) | — | "나오라"(18:4) |

---

계 17–18장은 결국 **구약 예언서의 반(反)제국 전승 전체를 하나의 환상으로 압축한 것**입니다. 새로운 계시가 아니라, 이미 말씀하신 것이 최종적으로 어디를 향하는지에 대한 개시(ἀποκάλυψις)입니다.
