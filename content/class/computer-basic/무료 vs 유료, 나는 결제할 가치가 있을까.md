> ⚠️ **주의**: 요금제 구성과 가격은 자주 바뀝니다. 이 글은 '판단 기준'을 다루며, 실제 금액과 기능은 결제 전 공식 페이지에서 확인하세요.

시즌 2의 마지막 질문입니다. "월 몇만 원, 낼 만한가요?"

이 질문에 "좋으니까 쓰세요"라고 답하는 글이 많습니다. 저는 계산해보고 결정하시라고 말씀드리고 싶습니다.

## 먼저: 유료로 바뀌는 것들

서비스마다 다르지만, 유료 전환 시 공통적으로 좋아지는 항목은 대체로 이렇습니다.

1. **더 좋은 모델 사용** — 무료는 가벼운 모델, 유료는 최상위 모델을 쓸 수 있는 구조가 일반적입니다. 복잡한 추론이나 긴 문서 작업에서 체감 차이가 큽니다.
2. **사용량 한도 증가** — 무료는 몇 번 쓰면 "한도에 도달했습니다"가 뜹니다.
3. **부가 기능** — 파일 업로드, 이미지 생성, 음성 대화, 데이터 분석, 웹 검색 연동 등이 무료에서는 제한되는 경우가 많습니다.
4. **혼잡 시간 우선 접속** — 사람이 몰릴 때 무료 사용자가 먼저 밀립니다.

## 손익분기점 계산법

간단합니다. 여러분의 **시간당 가치**를 대충 잡아보세요. 월급을 근무시간으로 나눠도 되고, 프리랜서면 시간당 단가를 쓰면 됩니다.

- 시간당 2만 원인 사람 → 월 3만 원 요금은 **월 1.5시간**을 아껴야 본전
- 시간당 5만 원인 사람 → **월 36분**만 아껴도 본전

한 달에 1시간 30분. 하루로 나누면 **하루 3분**입니다. 업무 메일 한 통 다듬는 시간, 회의록 정리 한 번, 자료 요약 한 번이면 하루 3분은 쉽게 나옵니다. 즉 **AI를 업무에 실제로 쓰고 있다면 손익분기점은 이미 넘었을 가능성이 큽니다.**

문제는 "실제로 쓰고 있는가"입니다. 결제만 하고 한 달에 세 번 쓰는 분도 많거든요.

## 이런 분은 유료가 확실히 이득

- 주 3회 이상 업무에 쓰고, 무료 한도에 걸린 경험이 있다
- 긴 문서(보고서, 논문, 계약서)를 다루는 일이 많다
- 코드를 쓰거나 데이터를 분석한다
- 파일 업로드·이미지 생성 같은 기능이 필요하다

## 이런 분은 무료로 충분

- 주 1~2회, 간단한 검색이나 글 다듬기 정도로 쓴다
- 무료 한도에 걸려본 적이 거의 없다
- 아직 프롬프트 쓰는 법에 익숙하지 않다 ← **이 경우 유료 결제보다 EP.01~02 연습이 먼저입니다**

## 결제 전 3단계 체크

**1단계. 2주간 무료로 매일 써보기**

한도에 몇 번 걸리는지 세어보세요. 한 번도 안 걸리면 유료가 급하지 않습니다.

**2단계. 하나만 먼저 결제**

여러 개 동시에 결제하지 마세요. 가장 자주 쓰는 것 하나만 한 달 써보고 판단하면 됩니다.

**3단계. 한 달 뒤 사용 기록 확인**

대화 목록을 열어보세요. 생각보다 안 썼다면 해지하고 무료로 돌아가도 괜찮습니다. AI는 언제든 다시 결제할 수 있습니다.

## 오늘의 실용 팁

**"무료 여러 개 조합"도 충분히 좋은 전략입니다.** 챗GPT 무료 한도가 차면 클로드로, 거기서도 차면 제미나이로 넘어가는 방식이죠. 교차 확인(EP.03)까지 자연스럽게 되니 오히려 장점도 있습니다. 결제는 "무료를 끝까지 써봤는데 부족하다"는 확신이 생긴 다음에 하세요.
