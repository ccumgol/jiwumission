## 1. 왜 필요한가 (3분)

> 🗣 "구독 결제는 보통 어디서 하세요? **폰이죠.
> **앱스토어에서 결제하고, 넷플릭스 앱에서 요금제를 올리고. 그 순간 노션에 기록하려면 PC를 켜야 한다면 — **안 합니다. 
> 기록은 일이 생긴 자리에서 해야** 남습니다."

### 모바일에서 되는 것 / 안 되는 것 (`01-023`)

미리 알려주면 실망하지 않습니다.

| 폰에서 |  |
| --- | --- |
| 폼으로 입력 | ✅ 아주 잘 됨 |
| 목록 보기 | ✅ 됨 (열이 많으면 답답) |
| 필터·정렬 **설정** | ⚠️ 불편 (PC에서 하세요) |
| 수식 작성 | ❌ 사실상 불가 |
| 단(칼럼) 레이아웃 | 위아래로 펼쳐져 보임 (`06-007`) |

> 🗣 "**폰은 입력용, PC는 설정용**으로 나눠 쓰세요. 이게 제일 편합니다."

## 2. 따라 만들기 — 홈 화면 아이콘 ★

> ⭐ **이 단계를 다 같이, 천천히 합니다.**
성공했을 때 반응이 가장 큰 순간입니다. 서두르지 마세요.

### iPhone / iPad

```
1. Safari 를 엽니다          ← ⚠️ 반드시 Safari
2. 폼 링크를 붙여넣어 엽니다
3. 아래쪽 「공유」 버튼 (□에 ↑ 모양)
4. 메뉴를 아래로 스크롤 → 「홈 화면에 추가」
5. 이름을 짧게:  구독
6. 「추가」
```

> 🚨 **iOS는 Safari에서만 됩니다.**

🗣 "크롬으로 열면 **'홈 화면에 추가'가 없습니다.** 그리고 카카오톡으로 링크를 보내서 열면 카톡 안에 있는 브라우저로 열려서 역시 안 됩니다.

**반드시 Safari 주소창에 직접** 붙여넣어야 합니다."

**링크를 폰으로 옮기는 방법**
· 같은 애플 계정이면 → PC Safari에서 복사하면 폰에 붙여넣기됩니다
· 아니면 → 나에게 메일/메모로 보내고, 폰에서 **링크를 길게 눌러 복사** → Safari에 붙여넣기

### Android

```
1. Chrome 을 엽니다
2. 폼 링크를 엽니다
3. 오른쪽 위  ⋮
4. 「홈 화면에 추가」 또는 「앱 설치」
5. 이름 입력 → 추가
```

### 성공 확인

```
폰 홈 화면으로 나갑니다
  → 새 아이콘이 있는지 확인
  → 눌러서 폼이 열리는지 확인
  → 실제로 하나 제출
  → PC에서 구독 DB를 열어 들어왔는지 확인
```

> 🗣 "여기서 성공하신 분 손 들어보세요. ⋯ 축하합니다.
> 여러분은 방금 **나만의 앱**을 만든 겁니다."

> 💡 **아이콘 위치를 정해주세요.**
"그 아이콘을 **첫 화면, 엄지가 닿는 자리**에 두세요. 두 번째 페이지에 있으면 안 누릅니다."

## 3. 모바일 전용 보기 만들기 (5분)

PC 보기를 폰에서 보면 열이 잘려서 답답합니다.

```
PC에서 작업합니다.
🗄 데이터 창고 → 🧾 구독 서비스 DB
  → 보기 탭의  +  →  「표」
  → 이름:  4강 · 📱 모바일
```

보이는 속성을 **3개만** 남깁니다 (`09-029`).

| 남길 속성 | 왜 |
| --- | --- |
| 서비스명 | 뭔지 알아야 |
| 월 환산액 | 얼마인지 |
| 최근 사용 | **폰에서 이걸 갱신하려고** |

> 🗣 "폰 화면은 좁습니다. **3개가 한계**예요.
> 그리고 폰에서 제일 많이 할 일이 `최근 사용` 날짜 찍기입니다.
> '아 이거 오늘 봤다' 하고 톡 찍는 거죠."

> 💡 **리스트 보기도 권해보세요** (`09-010`)
표가 답답하면 「리스트」 보기가 폰에서 더 편할 수 있습니다.
학습자에게 둘 다 보여주고 고르게 하세요.

## 4. 알림 정리 — 건너뛰지 마세요 (5분) (`12-023`)

> 🚨 **이 단계를 빠뜨리면 학습자가 며칠 만에 노션을 끕니다.**
🗣 "노션 알림을 기본값으로 두면 **하루에 몇 개씩** 옵니다. 내가 내 페이지 고친 것까지 알려주는 경우도 있어요.
시끄러우면 앱을 끕니다. 앱을 끄면 시스템이 죽습니다. **지금 정리합니다.**"

```
폰 노션 앱 → 설정 → 알림
  → 「멘션」 만 켠다
  → 나머지 끈다
```

| 알림 | 설정 | 이유 |
| --- | --- | --- |
| 멘션 | ✅ 켬 | 남이 나를 부를 때만 |
| 내 페이지 업데이트 | ❌ 끔 | 내가 한 걸 왜 알려주나 |
| 이메일 알림 | ❌ 끔 | 메일함이 지저분해진다 |

> 🗣 "혼자 쓰는 시스템이라 **알림이 거의 필요 없습니다.
> **나중에 팀으로 쓰게 되면 그때 켜세요."

## 6. 흔한 실수

| 실수 | 증상 | 해결 |
| --- | --- | --- |
| iOS에서 크롬으로 열었다 | 「홈 화면에 추가」가 없다 | **Safari**로 (`19-014`) |
| 카톡으로 링크 보내 열었다 | 카톡 내장 브라우저라 안 된다 | 링크 복사 → Safari 주소창 |
| 아이콘 이름이 길다 | 홈 화면에서 잘린다 | 2~3글자로 (`구독`) |
| 아이콘을 두 번째 페이지에 둠 | 안 누른다 | 첫 화면으로 옮긴다 |
| 모바일 보기에 열을 6개 넣음 | 여전히 답답하다 | 3개로 줄인다 |
| 알림 정리를 건너뜀 | 며칠 뒤 앱을 끈다 | 지금 정리 (`12-023`) |
| 폰에서 필터를 만들려 함 | 화면이 좁아 어렵다 | PC에서 설정 (`01-023`) |
