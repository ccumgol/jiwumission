## 이 강의 핵심 메시지

> 🗣 "시스템이 죽는 가장 큰 이유는 기능이 부족해서가 아니라
> **입력이 귀찮아서**입니다. 오늘은 그걸 없앱니다."

---

## 1. 왜 필요한가 (4분)

### 지금의 입력 과정을 같이 세어봅니다

> 🗣 "구독 하나를 추가해볼까요. 몇 번 클릭하는지 세어보세요."

```
노션 열기 → 사이드바 → 나의 일상 시스템 → 데이터 창고
  → 구독 DB → 맨 아래 「+ 새로 만들기」
  → 서비스명 → 금액 → 주기 → 결제일 → 결제수단 → 상태 → 최근 사용
```

> 🗣 "**클릭 15번, 입력 칸 7개입니다.
> **이걸 새 구독이 생길 때마다 하실 수 있나요?
> 못 합니다. 그래서 '나중에 하자' 하고, 나중은 안 옵니다.
> **DB가 죽는 건 기능이 없어서가 아니라 이 귀찮음 때문입니다.**"

### 폼으로 바뀌면

```
폼 링크 열기 → 3칸 쓰기 → 제출
```

> 🗣 "**8초입니다.** 그리고 노션에 로그인할 필요도 없습니다."

### 폼의 구조 (`17-017`)

> ⭐ **폼은 새 DB가 아니라 "입력 창구"입니다.**

🗣 "폼은 **DB의 얼굴**입니다. 데이터는 그대로 우리 구독 DB로 들어갑니다. 새로 생기는 게 아니에요."

```
폼 (입력 창구)  ──제출──▶  기존 구독 DB에 새 행으로 쌓임
```

## 2. 따라 만들기

### 단계 1 — 폼 보기 만들기 (`17-016`)

```
🗄 데이터 창고 → 🧾 구독 서비스 DB
  → 보기 탭의  +  클릭
  → 「폼」 선택
  → 이름:  3강 · 📝 구독 추가
```

![image](images/나의-일상-시스템-4강.-Forms(입력을-8초로)-1.webp)

### 단계 2 — 질문 4개만 만든다

폼을 만들면 **제목 속성(서비스명)만** 질문으로 들어가 있습니다.

나머지를 추가합니다.

```
폼 편집 화면에서
  → 「질문 추가」 또는 속성 목록에서 켜기
```

| 순서 | 질문 | 필수 | 왜 |
| --- | --- | --- | --- |
| 1 | 서비스명 | ✅ | 없으면 무슨 구독인지 모른다 |
| 2 | 금액 | ✅ | 이 시스템의 핵심 숫자 |
| 3 | 주기 (월/연) | ⬜ | 기본값 '월'로 두면 대부분 맞다 |
| 4 | 결제일 | ⬜ | 나중에 채워도 된다 |

![image](images/나의-일상-시스템-4강.-Forms(입력을-8초로)-2.webp)

![image](images/나의-일상-시스템-4강.-Forms(입력을-8초로)-3.webp)

> ⭐ **속성은 7개인데 질문은 4개만 만듭니다.**

🗣 "왜 4개만 물을까요? **폼이 길면 안 쓰게 됩니다.** 그게 폼을 만든 목적을 없애는 거죠.

`결제수단` `상태` `최근 사용`은 나중에 노션에서 채우면 됩니다. 일단 담고, 정리는 나중에." (`17-016`)

> 💰 **금액은 USD 기준입니다.(한국에서는 ‘원’ 기준)**
질문 설명(도움말)에 `USD 기준으로 입력` 이라고 적어두면 나중에 본인도 헷갈리지 않습니다.
>
> ![image](images/나의-일상-시스템-4강.-Forms(입력을-8초로)-4.webp)

### 단계 3 — 폼 꾸미기 (선택, 3분)

| 항목 | 예시 |
| --- | --- |
| 폼 제목 | `구독 추가` |
| 설명 | `새로 결제 시작한 구독을 기록합니다` |
| 제출 후 메시지 | `기록됐습니다` |

> 🗣 "제출 후 메시지를 꼭 넣으세요. 안 넣으면 제출됐는지 몰라서 두 번 누릅니다."

### 단계 4 — 공개 링크 발급 (`17-018`)

```
폼 화면 오른쪽 위의 「공유」 또는 「폼 공유」
  → 링크 만들기 / 공개하기
  → 링크 복사
```

![image](images/나의-일상-시스템-4강.-Forms(입력을-8초로)-5.webp)

> 🚨 **이 강의 가장 중요한 안전 수칙**

🗣 "**폼은 공개, 응답 DB는 비공개입니다.**

폼 링크를 받은 사람은 **쓸 수만** 있고 **볼 수는 없어야** 합니다. 이걸 헷갈리면 내 구독 목록과 금액이 통째로 공개됩니다.

지금 폼 공유 설정에서 **'응답 보기 허용'류 옵션이 꺼져 있는지** 확인하세요." (`17-017`)

### 단계 5 — 시크릿 창에서 테스트 (`17-018`)

> ⭐ **반드시 시크릿 창(새 프라이빗 창)에서 테스트하세요.**

🗣 "지금 브라우저는 여러분이 **로그인된 상태**입니다. 그래서 남이 보는 화면과 다릅니다. 시크릿 창으로 열어야 **진짜 남이 보는 화면**이 보입니다."

```
Chrome/Edge  Ctrl+Shift+N  (Mac: ⌘+Shift+N)
Safari       ⌘+Shift+N
```

![image](images/나의-일상-시스템-4강.-Forms(입력을-8초로)-6.webp)

테스트 순서:

```
1. 시크릿 창에 폼 링크 붙여넣기
2. 질문 4개가 잘 보이는지 확인
3. 테스트로 하나 제출
4. 노션 구독 DB로 돌아와 새 행이 생겼는지 확인
5. ✅ 확인했으면 테스트 행을 지운다
```

### 단계 6 — 입력하기 페이지에 정리

```
📝 입력하기 페이지를 열고
  → 폼 링크를 붙여넣기
  → 「북마크로 저장」 또는 텍스트 링크
  → 위에 콜아웃으로 설명 추가
```

> 🗣 "폼 링크를 잃어버리면 다시 찾기 번거롭습니다. **여기 한 곳에 모아둡니다.**"

## 3. 폼이 없을 때 — 버튼으로 대체 (`15-004`)

요금제에서 폼이 안 되면 **버튼 블록**으로 비슷하게 만듭니다.

```
🏠 홈 페이지 본문에서
  → /버튼   입력
  → 이름:  ➕ 구독 추가
  → 동작:  「페이지 추가」 → 대상: 🧾 구독 서비스 DB
  → 기본값 설정:  상태 = 이용중,  주기 = 월
```

|  | 폼 | 버튼 |
| --- | --- | --- |
| 노션 로그인 필요 | ❌ 안 필요 | ✅ 필요 |
| 폰에서 바로 쓰기 | ✅ 링크만 | 노션 앱 열어야 |
| 기본값 자동 채우기 | 제한적 | ✅ 잘 됨 |
| 입력 시간 | 8초 | 12초 정도 |

> 🗣 "버튼도 충분히 좋습니다. 4강의 홈 화면 아이콘만 **노션 앱**을 가리키게 하면 됩니다."

## 4. 흔한 실수

| 실수 | 증상 | 해결 |
| --- | --- | --- |
| 질문을 7개 다 만듦 | 폼이 길어 안 쓰게 된다 | 4개로 줄인다 |
| **응답 보기를 허용** | 내 구독 목록이 공개된다 | 즉시 끈다 (`17-017`) |
| 로그인 상태로 테스트 | 남이 보는 화면과 다르다 | 시크릿 창에서 (`17-018`) |
| 테스트 행을 안 지움 | DB에 쓰레기가 남는다 | 지운다 |
| 폼 링크를 어디 뒀는지 잊음 | 다시 찾기 번거롭다 | 📝 입력하기에 저장 |
| 새 DB를 만들어 폼을 붙임 | 데이터가 둘로 갈린다 | 기존 DB의 보기로 만든다 |
