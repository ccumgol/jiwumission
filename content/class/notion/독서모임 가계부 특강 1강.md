> 📘 독서모임 가계부 특강 1강(2026-11-19) 정리입니다. 노션을 처음 쓰거나 써 봤지만 정리가 안 된 분을 위해 설치와 사이드바 정리부터 시작해 노션의 세 가지 기초 개념인 페이지·블록·데이터베이스를 익히고, 공유받은 템플릿(가계부 DB, 일기 DB)을 복제해 내 것으로 맞추는 데까지 다룹니다. 마지막으로 캘린더와 폼으로 휴대폰에서 지출을 빠르게 입력하는 방법을 소개합니다.

## 이 강의에서 배우는 것

- 노션 설치·로그인과, 처음에 덜 막막하도록 사이드바를 정리하는 방법
- 기존 페이지를 "보관함"에 모으고 "홈" 페이지에서 새로 시작하는 방법
- 노션의 세 가지 기초 개념: **페이지, 블록, 데이터베이스**
- 데이터베이스 속성(선택·다중 선택·상태·날짜·생성 일시 등)의 차이와 쓰임
- 가계부·일기 템플릿을 복제해 분류·계좌·루틴을 내 것으로 바꾸기
- 캘린더 보기와 폼으로 휴대폰에서 지출 입력하기, 복제로 백업하기

## 1. 노션 설치와 로그인

1. 웹 브라우저 주소창에 [**notion.so**](http://notion.so/)를 입력합니다.
2. **Google로 로그인**하는 것이 가장 편합니다.
3. 용도를 물으면 **개인용**을 고릅니다. 아래의 워크스페이스 AI 개선 항목은 체크하지 않아도 됩니다.
4. **데스크탑 앱 다운로드**로 앱을 설치합니다(노션 캘린더도 함께). 화면은 웹과 같지만 접근이 편합니다.
5. 스마트폰은 앱스토어에서 "노션"을 검색해 받습니다.

- 모바일로는 모든 기능을 쓸 수 없습니다. 구조를 만드는 일은 컴퓨터에서 하고, 휴대폰은 **간단한 입력과 보기**용으로 쓰세요.

## 2. 사이드바 정리하기

노션 첫 화면이 막막하게 느껴지는 이유는 마우스를 가져다 대야 나타나는 메뉴가 많기 때문입니다. 처음에는 화면을 단순하게 만드는 것부터 시작합니다.

- 왼쪽 영역이 **사이드바**입니다. 위쪽 버튼으로 접고 펼 수 있어서, 노트북처럼 화면이 좁으면 접어 두고 필요할 때 엽니다.
- **점 6개(⋮⋮)** 는 항상 "끌어서 옮길 수 있다"는 표시입니다.

1. 사이드바 맨 아래 **사이드바 사용자 지정**을 엽니다.
2. **개인 페이지**를 맨 위로 끌어 올립니다.
3. 예정된 이벤트, 최근 항목, 공유된 페이지처럼 당장 쓰지 않는 섹션은 **사이드바에서 제거**한 뒤 **완료**를 누릅니다. 새 페이지·새 채팅 같은 버튼도 같은 방법으로 치울 수 있습니다.
4. 지운 섹션은 **섹션 추가**에서 언제든 다시 꺼낼 수 있습니다.

- **개인 페이지**는 나만 쓰는 작업 공간입니다. 처음에는 여기에 집중하세요. (공유된 페이지 섹션은 다른 사람을 초대하면 생깁니다.)
- **즐겨찾기**: 페이지 오른쪽 위 **별표**를 누르면 사이드바에 즐겨찾기가 생깁니다. 자주 보는 몇 개만 여기 두면 페이지가 많아도 바로 찾아갑니다.

## 3. 보관함과 홈 페이지

규칙 없이 써서 개인 페이지가 10개, 20개씩 쌓였다면 한 번 정리하고 새로 시작하는 것이 좋습니다.

1. 개인 페이지 옆 **+** 를 눌러 새 페이지를 만들고 제목을 **보관함 - 20261119**처럼 짓습니다.
2. 흩어져 있던 페이지를 끌어서 보관함 안으로 넣습니다. 끌 때 나타나는 **파란 선이나 파란 면**이 옮겨질 위치입니다.
3. 다시 **+** 로 **빈 페이지**(템플릿 말고)를 만들어 **홈**이라고 짓고, 앞으로 모든 작업은 홈 안에서 시작합니다.

- 보관함은 버리는 곳이 아니라서 필요하면 다시 꺼내 쓰면 됩니다.
- 웬만한 것은 홈 안에 두고, 자주 보는 것만 즐겨찾기에 올리세요.

## 4. 영상으로 보는 노션

노션 기초 영상 강좌 2편을 함께 시청했습니다. 핵심은 이렇습니다.

- 페이지는 노트 한 장이고, **블록**을 레고처럼 조립해 만듭니다. 페이지 안에 하위 페이지를 넣을 수 있습니다.
- 같은 종류의 페이지가 많아지면 **데이터베이스**로 모읍니다. **속성**(이름표)으로 검색·정렬·필터를 하고, **보기**를 바꿔 표·캘린더·보드로 봅니다.
- 가계부처럼 본문 없이 속성 값(분류·금액·결제 수단)만으로 기록하면 합계와 분류별 통계를 낼 수 있습니다.
- **관계형 속성**으로 데이터베이스끼리 연결하는 것이 노션의 진짜 강점입니다.
- 처음부터 큰 시스템을 만들 필요 없이, 내 필요에 맞게 작게 시작해 하나씩 덧붙이면 됩니다.

## 5. 작게 시작하는 가계부

노션의 가장 큰 장점은 **언제든 고쳐 쓸 수 있다**는 점입니다. 기능이 100가지인 가계부를 받아도 30가지만 쓴다면 나머지 70가지는 짐입니다. 하나로 시작해 기능을 붙여 나가면 그 시스템을 내가 완전히 알게 됩니다.

그래서 이번 특강은 **가계부 DB**와 **일기 DB** 두 개만 든 작은 템플릿(씨앗)에서 출발합니다. 1강에서는 기초 개념과 템플릿 복제, 두 DB의 용도와 커스터마이징을 다루고, 2강에서는 두 DB를 연결해 구조를 확장하며(데이터는 사라지지 않음), 3강에서는 대시보드를 만듭니다.

## 6. 페이지 이해하기

노션의 세 가지 기초 개념 중 첫 번째가 페이지입니다.

- **문서**: 텍스트와 자료가 들어가는 하나의 문서입니다. 페이지 위쪽에 상위 페이지 경로가 표시되어 바로 이동할 수 있습니다.
- **컨테이너**: 한 주제에 관한 글·그림·동영상·파일을 모아 두는 그릇입니다.
  - 그림 파일은 페이지에 끌어다 놓으면 들어갑니다.
  - 유튜브에서 **공유 → 링크 복사** 후 빈 곳에 붙여넣고 **동영상 임베드**를 고르면 페이지 안에서 바로 재생됩니다.
- **폴더(계층 구조)**: 하위 페이지를 만들어 계층으로 관리합니다. 사이드바에서 페이지에 마우스를 대면 나오는 **꺾쇠(>)** 를 누르면 하위 페이지가 펼쳐집니다.
- **협업 공간**: **공유**에서 상대의 노션 계정 이메일을 넣고 **초대**하면, 권한에 따라 함께 편집하거나 보기만 할 수 있습니다. 캠핑 계획처럼 여럿이 한 문서를 실시간으로 고치면 수정본을 다시 나눠 줄 필요가 없습니다.
- **작업장**: 여러 데이터베이스와 대시보드를 모아 한눈에 보는 역할도 합니다.

## 7. 블록 이해하기

레고가 몇 가지 조각으로 수만 가지 장난감을 만들듯, 노션 페이지도 몇 가지 블록으로 구성합니다.

- **블록 핸들(점 6개)**: 빈 곳을 클릭하면 왼쪽에 나타납니다. 블록을 옮기거나 메뉴(전환, 색 등)를 여는 가장 중요한 손잡이입니다. 옆의 **+** 를 누르면 추가할 수 있는 블록 목록이 나옵니다.
- **제목**: 4단계까지 있습니다. 제목으로 계층을 잡아 두면 오른쪽에 작은 막대가 생겨 원하는 위치로 바로 이동할 수 있고, `/목차` 블록으로 목차도 만들 수 있습니다.
- **전환**: 블록 핸들 → 전환으로 이미 만든 블록을 다른 종류(예: 텍스트 → 제목 2)로 바꿉니다.

블록을 만드는 두 가지 방법은 다음과 같습니다.

1. 빈 곳을 클릭해 **+** 를 누르고 원하는 블록을 고릅니다.
2. 빈 곳에서 키보드 **`/`****(슬래시)** 를 누르고 블록 이름을 입력합니다. `/페` 처럼 앞글자만 쳐도 찾아 줍니다. 손을 키보드에서 떼지 않아도 되어 문서를 많이 쓰는 분에게 가장 편합니다.

자주 쓰는 블록은 이렇습니다.

| 블록 | 설명 |
| --- | --- |
| 글머리 기호 목록 | 엔터마다 이어지고, 엔터를 한 번 더 치면 빠져나옴 |
| 번호 매기기 목록 | 1, 2, 3 번호가 자동으로 붙음 |
| 할 일 목록 | 체크하면 줄이 그어짐. 장보기 목록에 유용 |
| 토글 목록 | 내용을 접었다 폈다. 본문 흐름을 해치지 않고 보충 설명을 넣을 때 |
| 콜아웃 | 테두리가 있는 박스. 블록 핸들 → 색(위는 글자색, 아래는 배경색), 아이콘 변경 가능 |
| 인용 | 성경 본문 등 인용 표시 |
| 열 | 블록을 끌어 오른쪽에 세로선이 생기면 2열, 3열로 배치 |

- 이 밖에 표, 이미지·동영상·PDF 등 파일, 데이터베이스, 차트, 수학 공식도 있습니다.
- 링크는 **임베드**(페이지 안에서 재생) 대신 **북마크**(누르면 사이트로 이동)로도 넣을 수 있습니다.
- 블록을 끌 때 **파란 선**이 들여쓰기된 위치에서 시작하면 그 블록의 하위로 들어갑니다. 하위 블록은 상위 블록과 함께 움직입니다.

> 💡 콜아웃은 한 문서에 3개 이하로 쓰는 것을 권합니다. 너무 많으면 지저분해 보입니다. "기억할 점", "주의", "본문 요점"처럼 꼭 강조할 곳에만 쓰세요.

## 8. 데이터베이스 이해하기

가계부에서 가장 중요한 개념입니다. 데이터베이스도 블록이므로 `/데이터베이스`로 만듭니다. 이때 **인라인**과 **전체 페이지** 두 가지 방식이 나옵니다.

| 구분 | 인라인 | 전체 페이지 |
| --- | --- | --- |
| 모양 | 페이지 안에 표가 그대로 보임 | 하나의 하위 페이지처럼 들어감 |
| 장점 | 다른 내용을 보면서 구조를 짤 때 편함 | 항목이 많아도 다른 내용을 가리지 않음 |
| 캘린더 보기 | 한 달 단위로 보고 이전 달·다음 달로 이동 | 끊기지 않고 이어서 스크롤 |

- 항목이 5~10개 정도면 인라인도 괜찮지만, 가계부처럼 매일 쌓이는 데이터는 **결국 전체 페이지로 가야** 합니다.
- 처음에는 인라인으로 시작해도 되고, 나중에 블록 핸들 → **페이지로 전환**하면 됩니다.
- 데이터베이스 이름 옆(또는 기존 보기 옆) **+** → **새 보기**에서 **캘린더**를 추가하면 달력 모양으로 볼 수 있습니다.
- 지운 페이지는 사이드바의 **라이브러리 → 휴지통**에 **30일 동안** 보관됩니다. 실수로 지워도 되살릴 수 있습니다.

## 9. 템플릿 복제하기

1. 단톡방에 공유된 1강 템플릿 링크를 엽니다.
2. 열린 페이지의 설명서를 먼저 읽어 봅니다. 이 상태에서는 보기만 가능하고 블록 핸들도 나오지 않습니다.
3. 오른쪽 위의 **네모 두 개 아이콘(복제, Duplicate)** 을 누릅니다.
4. 추가할 곳으로 내 이름의 워크스페이스가 선택된 상태에서 **개인 페이지에 추가**를 누릅니다.
5. 사이드바에 **노션 가계부 특강** 페이지가 생깁니다. 이제 소유권이 내게 있으므로 마음대로 수정할 수 있습니다. 홈 안으로 끌어다 넣어 두면 좋습니다.

복제한 페이지 안에는 전체 페이지 데이터베이스 두 개(**일기**, **가계부**)가 들어 있습니다.

## 10. 일기 DB와 속성

일기 DB를 보기 전에 연습용으로 인라인 데이터베이스를 하나 만들어 속성을 익혔습니다.

1. `/데이터베이스` → 인라인을 고릅니다.
2. 흐릿하게 "새 데이터베이스"라고 적힌 곳에 **이름부터** 짓습니다.
3. "이름" 열을 클릭해 **제목**으로 바꿉니다.
4. **속성 추가**로 필요한 속성을 하나씩 만듭니다(예: 이름 "날짜", 유형 "날짜").

- **이름 짓기 규칙**: "일기" 페이지와 "일기" 데이터베이스가 함께 있으면 헷갈리므로, 강사는 DB 이름 끝에 **`_DB`** 를 붙입니다(예: `일기_DB`). 알아보기 쉬우면 어떤 이름이든 괜찮습니다.
- **제목(타이틀) 속성**: A 아이콘이 붙은, 항목을 대표하는 "반장"이라 **삭제할 수 없습니다**. 다른 속성은 클릭 → **속성 삭제**로 지웁니다.

속성 유형별 쓰임은 다음과 같습니다.

- **전화번호·이메일·URL**: 클릭하면 전화 걸기, 메일 보내기, 사이트 이동이 바로 됩니다.
- **선택 / 다중 선택**: 선택은 하나만, 다중 선택은 여러 개를 고릅니다. 설교문의 성경(마태복음)은 선택, 주제 태그(감사·기쁨)는 다중 선택입니다. 하루 날씨는 맑았다가 비가 올 수 있으니 다중 선택이 맞습니다.
- **상태**: 준비 중 → 작업 중 → 완료. 독서라면 산 책은 준비 중, 읽는 중은 작업 중, 다 읽으면 완료이고 "보류"도 더할 수 있습니다.
- **사람**: 공유된 사람 중 담당자를 지정합니다. **체크박스**는 했는지를 표시합니다.
- **생성 일시·최종 편집 일시** 등은 노션이 자동으로 기록합니다.

> 💡 가계부의 **분류는 반드시 선택(하나만)** 으로 하세요. 다중 선택으로 한 지출을 두 분류에 넣으면 나중에 통계가 이중으로 잡힙니다.

날짜 관련 속성 세 가지는 이렇게 다릅니다.

| 속성 | 특징 | 가계부에서 |
| --- | --- | --- |
| 날짜 | 직접 고르고 바꿀 수 있음 | 나중에 몰아서 입력한다면 가장 안전 |
| 생성 일시 | 만드는 순간 자동 기록, 수정 불가 | 그 자리에서 바로 입력하는 분에게 편함 (타임카드에 적합) |
| 최종 편집 일시 | 마지막 수정 시간이 찍힘 | 다음 날 메모만 고쳐도 날짜가 바뀌므로 쓰면 안 됨 |

## 11. 기분과 루틴 만들기

- **기분**: 하루에도 기분이 여러 번 바뀌니 **다중 선택**으로 만듭니다. 속성 클릭 → **속성 편집** → **옵션 추가**에서 아주 나쁨, 나쁨, 보통, 좋음, 아주 좋음 같은 옵션을 넣어 두면 새 항목에서 골라 쓸 수 있습니다. 속성 유형은 나중에 선택 ↔ 다중 선택으로 바꿀 수도 있습니다.
- **한 줄 일기, 감사 제목**: 텍스트 속성입니다.
- **루틴**: 템플릿에 체크박스 속성 5개(루틴 1~5)가 있습니다.
  1. "루틴 1"을 클릭해 "운동"처럼 내 루틴 이름으로 바꿉니다.
  2. 체크박스 열은 아주 좁게 줄일 수 있습니다. 그러면 이름이 안 보이므로, 속성 이름 옆 아이콘을 눌러 **아이콘**(예: 달리기)을 넣어 알아보게 합니다.
  3. 더 필요하면 **+** 로 체크박스 속성을 추가합니다(예: 독서).
- **제목 규칙**: 날짜 속성 값을 제목으로 쓸 수 없으니, 일기 제목은 **항상 같은 패턴**으로 입력하세요. 다른 방법은 나중에 알려 줄 예정입니다.
- 행의 **열기**를 누르면 그 항목도 하나의 페이지라 본문에 일기를 길게 쓸 수 있습니다. 휴대폰의 음성 입력으로 말하며 써도 됩니다.

## 12. 가계부 맞춤 설정

가계부 DB에도 제목, 날짜와 여러 선택 속성이 들어 있습니다. 내 생활에 맞게 바꾸는 것이 이번 주 핵심입니다.

- **분류**: 속성 편집에서 보면 "기타 지출"까지가 지출 항목, "급여"부터가 수입 항목입니다. 순서는 상관없습니다. 안 쓰는 항목(예: 주거비)은 삭제하고, 필요한 항목(예: 자산 수입)은 **+** 로 추가합니다.
- **계좌**(선택): 기본값은 은행 데빗·세이빙·크레딧, 현금, Venmo입니다. "은행 이름 + 데빗"처럼 내가 관리할 계좌를 넣고, 저축·투자 계좌나 돈을 넣어 두고 쓰는 Venmo 같은 가상 지갑도 포함합니다.
- **이체 방법**: 체크 발행, 은행 간 계좌, 현금, Venmo. 현금을 갖고 있는 것은 "계좌", 현금으로 준 것은 "이체"라서 양쪽에 다 있습니다.
- 삼성페이·애플페이는 카드에 연결된 것이니 어느 **계좌**에서 나갔는지 정확히 적어야 체킹 → 세이빙 같은 돈의 흐름을 추적할 수 있습니다.

> 💡 계좌 이름에 계좌 번호나 카드 번호는 절대 적지 마세요. "은행 이름 + 데빗"처럼 알아볼 수 있는 정도면 충분합니다.

## 13. 캘린더와 폼으로 입력

**캘린더 보기에서 입력하기**

1. 가계부의 "표" 보기 옆 **+** 를 눌러 **캘린더** 보기를 추가합니다.
2. 날짜 칸에 마우스(휴대폰은 손가락)를 대면 나오는 **+** 를 누릅니다.
3. 제목(예: "마트 장보기"), 계좌, 구분(수입/지출), 금액, 분류, 이체 방법, 메모를 입력하고 영수증 파일을 첨부합니다.
4. 필요한 선택지가 없으면(예: "카드 사용") 그 자리에서 새로 만들면 됩니다. 속성 순서도 점 6개를 끌어 입력하기 편하게 바꿀 수 있습니다.

**폼으로 입력하기** (강사가 가장 좋아하는 방법)

1. 보기 옆 **+** → **폼**을 고르고, **질문 N개로 만들기**를 누릅니다(데이터베이스 속성이 질문으로 자동 생성됨).
2. 폼 제목을 "지출 입력"처럼 짓습니다.
3. 권한 설정에서 기본값 "워크스페이스 멤버만 작성 가능"을 **변경** → **링크가 있는 웹의 모든 사용자**로 바꿉니다. "공개"로 표시됩니다.
4. **폼 링크 복사**를 누릅니다. 링크를 아는 사람은 나뿐이라 실제로는 나만 씁니다.
5. 링크를 휴대폰으로 옮깁니다. Mac·iPhone은 바로 붙여넣으면 되고, Windows·안드로이드는 카톡 "나와의 채팅"으로 보냅니다.
6. 휴대폰 브라우저에서 폼을 열고 공유 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 아이콘이 생깁니다.

- 휴대폰에서 영수증 업로드를 누르면 **카메라**가 열려 바로 찍어 첨부할 수 있습니다. 제출한 내용은 가계부 DB 표에 하나씩 쌓입니다.
- 노션 모바일 앱에서는 폼 원본을 보거나 수정할 수 없어서, 공개 링크를 브라우저로 여는 방식을 씁니다.
- 강사는 같은 방법으로 **차계부**를 씁니다. 주유 후 바로 마일리지·금액·영수증을 입력하면 영수증을 따로 보관할 필요가 없습니다.

## 14. 복제·백업과 보기

- **다시 복제하기**: 연습하다 분류를 지우는 등 망가졌다면 원래 링크에서 다시 복제해 오면 됩니다. 처음엔 연습용이라 생각하고 마음껏 시도하세요.
- **백업 사본**: 페이지의 **⋯** → **복제**로 사본을 만들어 "백업"을 붙여 둡니다. 작업본이 잘못되면 휴지통으로 보내고 백업본 이름을 되돌려 쓰면 됩니다. 데이터가 많이 쌓인 뒤에는 새로운 시도 전에 꼭 백업하세요.
- **보기는 데이터가 아닙니다**: 표, 캘린더, 리스트, 갤러리, 타임라인, 폼은 같은 데이터를 보여 주는 창일 뿐이라, 보기를 삭제해도 데이터는 그대로입니다.
