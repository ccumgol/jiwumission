‘나의 일상 시스템’은 노션의 기능을 하나씩 익히면서, 내 생활에 실제로 필요한 관리 도구를 직접 만들어 가는 시리즈입니다. 완성된 템플릿을 그대로 복제하기보다 빈 화면에서 시작해, 오래 사용할 수 있는 작고 단순한 시스템을 만드는 데 목적이 있습니다.

앞선 과정에서는 구독 서비스 데이터베이스를 만들고, 필요한 정보만 홈에 보여 주는 보기와 간편하게 기록하는 폼을 살펴보았습니다. 이번 글은 그 방법을 **습관, 독서, 집안일 등 다른 생활 영역에 다시 적용하는 선택 과정**입니다.

처음 이 시리즈를 접했다면 [나의 일상 시스템 1강. 틀 만들기 — 페이지 5개로 시작하기](https://app.notion.com/p/3e8091c284f6816b9d41d20732be4dd7)와 [나의 일상 시스템 2강. 첫 데이터베이스 — 구독 관리로 시작하기](https://app.notion.com/p/3e8091c284f681fc9fd2ca3c17220ac5)부터 살펴보세요. 데이터베이스, 보기, 폼이 처음이라면 앞선 과정을 따라 한 뒤 이 글로 돌아오면 더 수월합니다.

## 이번에는 새로운 기능보다 반복이 중요합니다

처음 구독 관리 시스템을 만들 때는 어디를 눌러야 할지 하나하나 살펴봐야 했을 것입니다. 같은 과정을 다른 주제에 적용해 보면 기능을 외우기보다 **내 필요에 맞게 구성하는 방법**이 익숙해집니다.

만드는 순서는 네 단계입니다.

1. **데이터베이스 만들기**: 기록을 저장할 원본을 데이터 창고에 만듭니다.
2. **보기 만들기**: 필터나 정렬을 적용해 필요한 기록만 보여 줍니다.
3. **폼 만들기**: 자주 입력하는 내용을 간단한 질문으로 만듭니다.
4. **홈에 연결하기**: 매일 확인할 필요가 있다면 링크된 보기를 홈에 올립니다.

데이터베이스가 기록을 보관하는 곳이라면, 보기는 같은 기록을 필요한 방식으로 보여 주는 화면입니다. 폼은 기록을 넣는 입구이고, 홈은 자주 확인하는 정보를 모아 두는 곳입니다.

## 무엇을 만들지 고르는 기준

화려한 템플릿보다 **지금 없어서 불편한 것**부터 골라 보세요. 책을 읽고도 어디까지 읽었는지 잊어버리는지, 집안일을 언제 했는지 기억나지 않는지처럼 실제로 겪는 불편이 출발점입니다.

다음 여섯 가지 중에서 골라도 좋고, 자신의 생활에 맞는 다른 주제를 정해도 좋습니다.

| 주제 | 이런 불편이 있을 때 | 중심이 되는 속성 |
| --- | --- | --- |
| 🔁 습관 트래커 | 실천한 날을 기억하기 어렵다 | 날짜와 완료 여부 |
| 📖 독서 기록 | 읽다 멈춘 책이 쌓인다 | 읽다 만 날 |
| 🎬 영화·드라마 | 무엇을 언제 봤는지 잊는다 | 본 날짜 |
| 🛒 위시리스트 | 사고 싶은 물건을 충동적으로 구매한다 | 담은 날 |
| 🍜 맛집 기록 | 다시 가고 싶은 곳을 잊는다 | 재방문 의사 |
| 🧹 집안일 | 마지막으로 한 때가 기억나지 않는다 | 마지막 한 날 |

### ‘심장이 되는 속성’이란?

속성은 데이터베이스에 기록하는 정보의 종류입니다. 예를 들어 책 제목, 저자, 읽기 상태는 각각 하나의 속성입니다.

그중 **심장이 되는 속성**은 단순한 기록을 넘어 다음 행동을 결정하는 데 도움이 되는 정보입니다.

- 독서 기록의 `읽다 만 날`을 보면 계속 읽을지 정리할지 생각할 수 있습니다.
- 위시리스트의 `담은 날`을 보면 시간이 지난 뒤에도 필요한 물건인지 다시 판단할 수 있습니다.
- 집안일의 `마지막 한 날`을 보면 다시 할 때가 되었는지 살펴볼 수 있습니다.

모든 기록이 반드시 이런 속성을 가져야 하는 것은 아닙니다. 다만 ‘이 기록을 보고 무엇을 결정할까?’를 먼저 생각하면 불필요한 항목을 줄이는 데 도움이 됩니다.

### 몇 개를 만들면 좋을까요?

반복 연습을 위해 **2~4개**를 권합니다. 다만 한 번에 모두 만들 필요는 없습니다. 가장 필요한 것 하나부터 실제로 사용해 보고, 관리할 여유가 있을 때 추가하세요.

## 가볍게 만들기 위한 공통 규칙

| 규칙 | 이유 |
| --- | --- |
| 데이터베이스 원본은 `🗄 데이터 창고`에 만들기 | 원본을 한곳에서 찾고 관리하기 쉽습니다. |
| 속성은 제목을 포함해 7개 이하로 시작하기 | 입력하고 관리할 부담을 줄입니다. |
| 폼 질문은 4개 이하로 시작하기 | 자주 기록할 때 번거로움을 줄입니다. |
| 보기 이름에 `확장 ·` 붙이기 | 이 과정에서 만든 보기를 알아보기 쉽습니다. |
| 중심이 되는 속성 정하기 | 기록이 어떤 판단에 도움이 될지 생각합니다. |
| 홈에는 자주 볼 것만 올리기 | 홈을 복잡하게 만들지 않습니다. 이 과정에서는 링크된 보기 5개 이하를 기준으로 삼습니다. |

이 숫자들은 노션의 제한이 아니라, 작게 시작하고 계속 사용하기 위한 **이 과정의 권장 기준**입니다.

## 함께 만들어 보기: 습관 트래커

이제 실제 예시로 습관 기록을 만들어 보겠습니다. 핵심은 하루에 무엇을 실천했는지 간단하게 남기고, 오늘의 기록을 홈에서 확인하는 것입니다.

### 1단계. 데이터베이스 만들기

`🗄 데이터 창고` 페이지에서 새 데이터베이스를 만들고 이름을 `🔁 습관 기록`으로 정합니다. 데이터베이스에는 제목 속성이 반드시 하나 있으므로, 기본 제목 속성을 `기록`으로 바꿉니다.

| 속성 | 유형 | 입력할 내용 |
| --- | --- | --- |
| 기록 | 제목 | 예: `아침 운동` |
| 날짜 | 날짜 | 습관을 실천할 날짜 |
| 습관 | 선택 | `운동`, `독서`, `영어` 등 |
| 완료 | 체크박스 | 실천했으면 체크 |
| 메모 | 텍스트 | 필요한 경우 한 줄 기록 |

예를 들어 `아침 운동`이라는 제목으로 기록을 만들고 날짜와 습관을 선택한 뒤, 운동을 마치면 `완료`를 체크합니다.

### 2단계. 보기 만들기

같은 데이터베이스에 두 가지 보기를 만들어 봅니다.

| 보기 이름 | 유형 | 설정 |
| --- | --- | --- |
| `확장 · 📅 이번 달` | 캘린더 | `날짜` 속성을 기준으로 표시 |
| `확장 · ✅ 오늘` | 표 | 필터에서 `날짜`가 `오늘`인 항목만 표시 |

캘린더에서는 기록을 날짜별로 살펴볼 수 있고, 표에서는 오늘 필요한 항목만 볼 수 있습니다. **데이터는 하나지만 보는 방식은 여러 가지**인 셈입니다.

### 3단계. 폼 만들기

습관 기록 데이터베이스에서 폼 보기를 만들고, `기록`, `날짜`, `습관`, `완료`를 질문으로 설정합니다. 메모가 꼭 필요하지 않다면 폼에서는 빼도 됩니다.

폼을 제출해 테스트 기록을 하나 넣고, 데이터베이스에 정상적으로 추가되는지 확인하세요. 개인 기록인 만큼 폼과 응답 데이터베이스의 공유 범위도 사용 목적에 맞게 확인합니다.

### 4단계. 홈에 필요한 보기만 올리기

`🏠 홈`에서 링크된 데이터베이스 보기를 추가하고, 원본으로 `🔁 습관 기록`을 선택합니다. 오늘의 기록만 보이도록 `확장 · ✅ 오늘` 보기를 선택하거나 같은 필터를 적용합니다.

홈에는 매일 확인할 필요가 있는 경우에만 올려 두세요. 이미 링크된 보기가 많다면 덜 자주 보는 것은 홈에서 내려 데이터 창고에서 확인해도 됩니다. **홈에서 보기를 제거해도 원본 데이터베이스를 삭제하는 것은 아닙니다.**

### 선택: 반복 템플릿 사용하기

매일 같은 습관을 기록한다면 데이터베이스의 `새로 만들기` 옆 메뉴에서 템플릿을 만들고 반복을 설정해 볼 수 있습니다. 예를 들어 `아침 운동`이라는 제목과 `운동` 선택값을 기본으로 정해 두는 방식입니다.

반복으로 생성된 항목의 `날짜`가 오늘 보기의 필터에 맞게 들어가는지 먼저 확인하세요. 사용하지 않은 빈 항목이 쌓일 수도 있으므로, 습관 기록이 익숙해진 뒤에 적용해도 충분합니다.

## 다른 주제로 확장하기

습관 트래커를 만들었다면 같은 순서를 다른 주제에 적용해 보세요. 아래 속성은 출발점일 뿐입니다. 쓰지 않을 항목은 빼고, 실제로 필요한 것만 남기세요.

### 📖 독서 기록

| 속성 | 유형 |
| --- | --- |
| 책 제목 | 제목 |
| 저자 | 텍스트 |
| 상태 | 선택: `읽는 중`, `다 읽음`, `멈춤` |
| 시작일 | 날짜 |
| 다 읽은 날 | 날짜 |
| ★ 읽다 만 날 | 날짜 |
| 한 줄 평 | 텍스트 |

갤러리 보기를 만들고 책 표지를 카드 커버로 표시하면 책을 시각적으로 살펴보기 좋습니다. 책을 잠시 멈출 때 `읽다 만 날`을 기록해 두면 나중에 다시 시작할지 판단하는 데 도움이 됩니다.

### 🎬 영화·드라마 기록

| 속성 | 유형 |
| --- | --- |
| 제목 | 제목 |
| 별점 | 선택: ⭐~⭐⭐⭐⭐⭐ |
| 장르 | 다중 선택 |
| ★ 본 날짜 | 날짜 |
| 어디서 | 선택: 넷플릭스, 디즈니+, 극장 등 |

`어디서`를 기록하면 서비스별로 무엇을 봤는지 필터링할 수 있습니다. 나중에 관계형 속성을 배우면 구독 데이터베이스와 연결하는 방법도 살펴볼 수 있습니다. 단순한 선택 속성만으로 두 데이터베이스가 자동 연결되지는 않습니다.

### 🛒 위시리스트

| 속성 | 유형 |
| --- | --- |
| 물건 | 제목 |
| 가격 | 숫자: 미국 달러(USD) |
| 상태 | 선택: `보는 중`, `샀음`, `안 사기로 함` |
| ★ 담은 날 | 날짜 |
| 링크 | URL |

`담은 날`을 기준으로 30일 이상 지난 항목을 보는 필터를 만들어 보세요. 시간이 지난 뒤에도 갖고 싶은지 다시 확인하면 구매를 더 신중하게 결정할 수 있습니다. 30일은 정답이 아니라 스스로 정해 볼 수 있는 대기 기간입니다.

### 🍜 맛집 기록과 🧹 집안일

| 주제 | 시작할 때 필요한 속성 | 활용 방법 |
| --- | --- | --- |
| 맛집 기록 | 가게명(제목), 분류, 평점, 재방문 의사, 위치 메모, 사진 | 다시 가고 싶은 곳을 골라 봅니다. |
| 집안일 | 할 일(제목), 주기(일), 마지막 한 날 | 마지막으로 한 날짜를 보고 다시 할 때가 되었는지 확인합니다. |

집안일에 익숙해지면 수식으로 마지막으로 한 날부터 며칠이 지났는지 계산해 볼 수도 있습니다. 처음부터 수식을 만들 필요는 없습니다.

## 자주 생기는 어려움

| 어려움 | 이렇게 조정해 보세요 |
| --- | --- |
| 한꺼번에 여러 개를 만들고 관리하기 어렵다 | 가장 필요한 것부터 하나씩 사용해 봅니다. |
| 속성이 너무 많아 입력하기 귀찮다 | 자주 쓰는 정보만 남기고 7개 이하로 줄입니다. |
| 기록만 쌓이고 다시 보지 않는다 | 어떤 판단에 쓸 기록인지 정하고, 관련 속성이나 보기를 추가합니다. |
| 홈이 복잡해졌다 | 자주 보는 링크된 보기만 남기고 나머지는 데이터 창고에서 확인합니다. |
| 데이터베이스를 홈에 만들었다 | 원본을 데이터 창고에 두고, 홈에는 필요한 링크된 보기만 배치합니다. |
| 처음에는 멋져 보였지만 쓰지 않는다 | 실제 생활에서 불편한 문제를 해결하는 주제로 바꿔 봅니다. |

## 마무리 체크리스트

주제를 하나 만들 때마다 확인해 보세요.

- [ ] 데이터베이스 원본을 `🗄 데이터 창고`에 만들었다.
- [ ] 제목을 포함해 속성을 7개 이하로 정리했다.
- [ ] 기록을 보고 어떤 판단을 할지 생각했다.
- [ ] 필요한 보기를 1~2개 만들고 이름에 `확장 ·`을 붙였다.
- [ ] 자주 입력할 질문 4개 이하로 폼을 만들고 테스트했다.
