> 🎯 **학습 목표:** 데이터의 성격에 맞는 속성을 골라 구조화된 정보를 만들 수 있다.

## 7-1. 속성(Property)이란?

데이터베이스의 **열(column)이 곧 속성**입니다. 각 속성은 '어떤 종류의 데이터를 담을지'를 정합니다. 예를 들어 날짜 속성은 날짜만, 숫자 속성은 숫자만 받습니다. 속성을 잘 고르는 것이 데이터베이스 설계의 핵심입니다.

> 📸 **[캡처 7-1]** 속성 유형 선택 메뉴 — 텍스트·숫자·선택·날짜·사람 등 유형이 리스트로 나오는 화면.

## 7-2. 자주 쓰는 기본 속성

| 속성 | 쓰임새 |
| --- | --- |
| 텍스트 | 메모·설명 등 자유 입력 |
| 숫자 | 금액·수량·점수 |
| 선택 / 다중선택 | 카테고리·태그(미리 정해둔 값 중 고르기) |
| 날짜 | 마감일·일정 |
| 체크박스 | 완료 여부(쿤/끕) |
| 사람(Person) | 담당자 지정 |
| 파일·미디어 | 첨부 파일·이미지 |

## 7-3. 상태(Status) 속성

진행 단계를 관리하는 전용 속성입니다. 값을 **할 일 / 진행 중 / 완료** 세 그룹으로 묶어주어 보드 뷰와 잘 어울립니다.

## 7-4. 자동 속성

손으로 입력하지 않아도 Notion이 채워주는 속성도 있습니다: **생성 일시, 최종 편집 일시, 생성자, 최종 편집자**. 기록 관리에 유용합니다.

## 7-5. 속성 추가·숨기기·순서 바꾸기

표 오른쪽 끝 **+** 로 속성을 추가하고, 속성 머리를 클릭해 이름·유형을 바꾸거나 숨길 수 있습니다. 자주 안 보는 속성은 숨기면 화면이 깔끔해집니다.

> 📸 **[캡처 7-2]** 속성 머리 클릭 시 나타나는 메뉴(이름 변경·유형 편집·숨기기·삭제)를 보여주기.

## 📖 용어정리

| 용어 | 뜻 |
| --- | --- |
| 속성(Property) | 데이터베이스의 열. 데이터의 종류를 정의 |
| 선택/다중선택 | 미리 정해둔 값 중 하나/여러 개를 고르는 속성 |
| 상태(Status) | 진행 단계를 그룹으로 관리하는 전용 속성 |
| 자동 속성 | 생성일·편집자 등 Notion이 자동으로 채우는 속성 |

## ❓ FAQ

**Q. 선택과 다중선택은 어떻게 다른가요?**

A. 선택은 한 개만(예: 우선순위 '높음'), 다중선택은 여러 개(예: 태그 '기획, 디자인')를 고를 수 있습니다.

**Q. 속성을 지우면 데이터도 지워지나요?**

A. 네, 해당 열의 값이 모두 사라집니다. 지우기 대신 '숨기기'를 쓰면 값은 유지됩니다.

**Q. 상태와 선택 중 뭘 쓰죠?**

A. 진행 단계(할 일/진행/완료)처럼 흐름이 있으면 상태, 단순 분류면 선택이 적합합니다.

## 💡 Tips

- 선택·상태 값은 **색상**을 지정해 한눈에 구분되게 하세요.
- 필요 없는 속성은 숨겨서 입력 시 집중도를 높이세요.
- 다중선택은 태그처럼 써서 나중에 필터·검색으로 분류하기 좋습니다.
