> 🎯 **학습 목표:** 하나의 데이터를 여러 페이지에서 불러와 보여줄 수 있고, 원본과 링크본의 차이를 구분할 수 있다.

## 6-1-1. 링크된 데이터베이스란?

다른 곳에 있는 데이터베이스를 **복사하지 않고 그대로 불러와** 현재 페이지에 보여주는 기능입니다. 데이터는 한 군데(원본)에만 존재하고, 여러 페이지에서 창문처럼 들여다보는 것입니다.

그래서 어느 쪽에서 내용을 고쳐도 **모든 곳에 즉시 반영**됩니다. 복사본을 여러 개 만들어 서로 달라지는 문제가 사라집니다.

**실무 예시**

- 팀 전체 '할 일' DB → 내 개인 페이지에는 '내 할 일'만 필터해 표시
- '고객' DB → 각 프로젝트 페이지에 관련 고객만 보이기
- 회의록 페이지 안에 '이번 주 일정'만 뾽아 보여주기

> 📸 **[캡처 6-1-1]** 왼쪽에 원본 데이터베이스, 오른쪽에 다른 페이지의 링크된 뷰를 나란히 놓고, 한쪽을 수정하면 다른 쪽도 같이 바뀌는 것을 보여주기.

## 6-1-2. 데이터 소스(Data Source) 개념

최신 Notion에서는 데이터베이스를 이루는 실제 데이터 묶음을 **데이터 소스**라고 부릅니다. 모든 데이터베이스는 최소 하나의 데이터 소스를 가지며, 하나의 데이터베이스에 **여러 데이터 소스를 묶어서** 관리할 수도 있습니다.

| 구분 | 설명 |
| --- | --- |
| 원본(Sources) | 이 데이터베이스에서 시작된 진짜 데이터 |
| 링크됨(Linked) | 다른 데이터베이스에서 가져온 데이터 |

확인하려면 데이터베이스 상단 설정(슬라이더) 아이콘 → **데이터 소스 관리**를 열면 됩니다.

## 6-1-3. 만드는 방법

1. 불러오고 싶은 페이지에서 `/` 를 입력합니다.
2. **데이터베이스**를 선택한 뒤, 메뉴에서 **기존 데이터 소스에 연결(Link to existing data source)**을 고릅니다.
3. 가져올 데이터베이스를 검색해 선택합니다.
4. 불러온 뒤 **필터·정렬·뷰 형태**를 이 페이지에 맞게 자유롭게 설정합니다.

> 📸 **[캡처 6-1-2]** `/` 입력 → 데이터베이스 선택 시 나타나는 '새 데이터베이스 / 기존 데이터 소스에 연결' 선택 화면.

## 6-1-4. 어디까지 같이 바뀔까? (가장 중요)

링크된 데이터베이스에서의 변경은 두 종류로 나뉩니다.

| 내가 바꿔도 원본은 그대로 | 바꾸면 원본까지 같이 바뀜 |
| --- | --- |
| 뷰 추가·삭제 | 항목(행)의 내용 |
| 필터 · 정렬 · 그룹화 | 속성 이름·종류 변경 |
| 보이는 속성 숨기기 | 데이터 소스 제목 |

즉, **"보이는 방식"은 나만의 것, "데이터 자체"는 모두의 것**입니다. 내 페이지에서 필터를 바꿔도 동료 화면은 멀집하지만, 항목 내용을 고치면 모두에게 반영됩니다.

## 6-1-5. 권한 주의사항

링크된 데이터베이스는 **원본의 권한을 그대로 따릅니다.** 내 페이지를 공유해도 상대방에게 원본 데이터베이스 접근 권한이 없으면 내용이 보이지 않습니다. "저는 빈 화면이 보여요"라는 제보를 받으면 먼저 원본 권한부터 확인하세요.

## 📖 용어정리

| 용어 | 뜻 |
| --- | --- |
| 링크된 데이터베이스 | 원본 데이터를 다른 페이지에서 불러와 보여주는 뷰 |
| 데이터 소스 | 데이터베이스를 이루는 실제 페이지 묶음 |
| 원본(Sources) | 해당 데이터베이스에서 시작된 데이터 |
| 동기화 | 한 곳의 변경이 연결된 모든 곳에 반영되는 것 |

## ❓ FAQ

**Q. 복사(복제)와 뭐가 다른가요?**

A. 복제는 따로 녹는 별개의 데이터베이스가 되지만, 링크는 원본과 계속 연결되어 항상 같은 내용을 유지합니다.

**Q. 링크된 뷰에서 항목을 지우면 어떻게 되나요?**

A. 원본에서도 삭제됩니다. 화면에서만 감추고 싶다면 삭제 대신 **필터**를 쓰세요.

**Q. 상대방에게 데이터가 안 보인대요.**

A. 원본 데이터베이스에 그 사람을 초대했는지 확인하세요. 링크본은 원본 권한을 따릅니다.

**Q. 폼(Form) 뷰가 안 보여요.**

A. 링크된 데이터베이스에는 폼을 추가할 수 없습니다. 원본 데이터베이스로 가서 만드세요. (→ Chapter 6-2)

## 💡 Tips

- 데이터베이스는 **한 군데에만 원본을 두고**, 필요한 곳마다 링크로 뿐려 쓰세요. 이게 정리의 핵심입니다.
- 개인 대시보드를 만들 때 여러 DB를 링크해 '내 일감' 한 장을 구성해 보세요.
- 링크본은 제목 옆에 ↗ 표시가 붙습니다. 원본인지 링크본인지 헷갈릴 때 확인하세요.
